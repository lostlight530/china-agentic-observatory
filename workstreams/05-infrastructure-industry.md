# C5｜Chips, Compute, Data, Terminals, and Industrial Infrastructure / 芯片、算力、数据、终端与产业基础设施

C5 tracks China's AI infrastructure stack: accelerators, domestic computing ecosystems, cloud/data centers, networking/storage, data systems, edge/terminal devices, AI phones/PCs, robotics hardware, industrial platforms, energy/resource constraints, and the supply/deployment conditions that shape practical capability.

## Core questions

- What exact infrastructure object exists, at what release/deployment scale and geography?
- Is a figure a chip specification, lab benchmark, cluster result, planned capacity, installed capacity, cloud-service limit, shipment, or observed production metric?
- Which bottleneck is being addressed: compute, memory bandwidth, interconnect, storage, data, power, thermal, supply chain, software compatibility, cost, latency, or deployment access?
- Does a domestic stack claim describe component substitution, ecosystem compatibility, end-to-end deployment, or independent performance equivalence?
- Are terminal/robot/industrial deployments pilots, named deployments, commercial products, or broad industry adoption?

## Preferred evidence

Prefer manufacturer/platform specifications for product identity, original system papers, cloud/provider documentation, government/public procurement or industrial-policy sources where relevant, company disclosures for their own deployments, and independent system measurements for generalized performance claims.

## Infrastructure boundaries

```text
announced capacity != installed capacity
installed capacity != utilized production capacity
peak specification != application performance
shipment != deployment
pilot deployment != industry-wide adoption
component availability != end-to-end ecosystem maturity
domestic replacement claim != measured equivalence
```

Preserve geography, scale, configuration, time window, software stack, measurement basis, and whether a figure is planned/reported/independently observed.

## Handoff to C8

C5 contributes the exact infrastructure object, maturity/deployment scale, geography, measurement basis, constraints/bottlenecks, evidence source, and the narrow industrial implication supported.

C5 does not infer model quality, agent reliability, national self-sufficiency, or market dominance from one component/capacity signal alone.

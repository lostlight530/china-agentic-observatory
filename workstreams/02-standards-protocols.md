# C2｜Standards, Protocols, Identity, and Interconnection / 标准、协议、身份与互联

C2 tracks China-specific standards and interoperability structures: national, industry, local/group/association standards where relevant; agent/AI protocol proposals; identity codes; discovery; interaction; tool invocation; gateways; trust/interconnection; and compatibility with global protocol families.

## Core questions

- What kind of standard or technical document is this, who issued it, and what is its formal status?
- Is the item a proposal, project, draft, consultation text, approved standard, published standard, implementation guide, reference architecture, or observed conformance program?
- Does a protocol describe discovery, identity, message exchange, tool invocation, task state, authorization, or trusted interconnection—and which layer owns each property?
- Is compatibility documented, implemented, tested, or merely described as a goal?
- Does a China-specific profile extend, map to, or independently solve a problem also addressed by MCP/A2A or other global systems?

## Preferred evidence

Prefer official standard publishers, competent standards bodies, ministry/agency standard notices, formal project/draft/publication pages, primary technical documents, and source repositories/SDK documentation for implementation claims.

Company or alliance explanations may clarify intent or implementation but must not silently change the formal status of a standard.

## Standard and protocol boundaries

```text
technical document != GB/T national standard
project initiated != standard published
standard published != implementation deployed
reference architecture != interoperable system
identity field defined != identity verified
discovery supported != authorization granted
protocol compatible in principle != conformance tested
```

Always retain standard number/version/status, issuing organization, publication/effective date when applicable, and the precise technical layer being compared.

## China–global comparison boundary

Compare like with like:

```text
standard ↔ standard
protocol ↔ protocol
SDK/runtime ↔ SDK/runtime
deployment ↔ deployment
```

Do not compare a Chinese policy/standard objective directly with a foreign vendor product and call the difference technical maturity.

## Handoff to C8

C2 contributes the exact standards/protocol object, formal state, version/date, technical layer, identity/authority semantics, implementation/conformance evidence, comparison target, and unresolved maturity gaps.

C2 does not infer universal adoption, technical effectiveness, or national interoperability from document publication alone.

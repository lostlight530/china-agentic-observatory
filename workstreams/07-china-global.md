# C7｜China–Global Relationship / 中国与全球路线关系

C7 owns same-layer comparison between China-specific trajectories and global AI/agent systems. Its purpose is to identify genuine convergence, divergence, translation, compatibility, and institutional difference without treating one side's vocabulary as the default ontology for the other.

## Core questions

- Are the compared objects actually the same layer: policy, standard, protocol, SDK/runtime, model, platform, deployment, evaluation, or governance mechanism?
- Do similar words refer to the same technical/institutional function?
- Is a difference caused by architecture, regulation, market structure, institutional role, maturity, terminology, or evidence availability?
- Is compatibility documented, implemented, tested, or only strategically desired?
- Does a China-specific mechanism complement, extend, compete with, or remain orthogonal to a global mechanism?

## Comparison discipline

Compare like with like:

```text
policy ↔ policy
standard ↔ standard
protocol ↔ protocol
model ↔ model
runtime/SDK ↔ runtime/SDK
deployment ↔ deployment
evaluation ↔ evaluation
```

Do not use a foreign vendor product as the comparator for a Chinese national policy, or a Chinese technical standard as the comparator for a foreign commercial deployment, without explicitly explaining the layer mismatch.

## Evidence discipline

Use each side's strongest proposition-specific primary sources and preserve local status vocabulary. A source authoritative in one institutional system does not automatically define the other's maturity categories.

Translation should preserve formal nouns, version identifiers, administrative levels, dates, and explicit uncertainty rather than forcing false equivalence.

## Relationship boundaries

```text
similar objective != same mechanism
same mechanism != same governance
compatibility claim != interoperability test
shared protocol family != identical implementation maturity
China-specific term != direct English/global synonym
```

## Handoff to C8

C7 contributes the two exact objects being compared, the comparison layer, versions/status/dates, evidence source on each side, genuine commonality, genuine divergence, unknowns, and any layer mismatch that limits inference.

C7 does not rank national systems or infer superiority from incomparable evidence surfaces.

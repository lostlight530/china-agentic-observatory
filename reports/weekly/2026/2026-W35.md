
The final W35 model is:

```text
APPLICATION / OPERATION
→ FEEDBACK
→ EVALUATION / DIAGNOSIS
→ TARGETED DATA WORK
→ DATASET VERSION
→ PROVENANCE
→ VERSION-SCOPED QUALITY EVIDENCE
→ APPLICABILITY / RE-EVALUATION / GOVERNANCE DECISION
→ MODEL ITERATION
→ FOLLOW-UP EVALUATION
```

The chain is an observatory synthesis. No source establishes it as one national automated architecture.

The strongest weekly conclusion is:

> **China has increasingly explicit lifecycle components for feedback-driven dataset correction, but the formal machine-readable crosswalk among feedback events, data work items, dataset versions, quality results, rights and later model state remains open.**

## Historical-state rule

Closed weeklies are not rewritten merely because later evidence advances a project state.

```text
old weekly = what was known / observed then
later daily + registry + monthly correction = current state
```

A closed weekly is modified only when the weekly itself contains a factual error requiring explicit correction.

## Legacy files

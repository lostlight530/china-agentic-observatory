## 2｜开周信号 — 2026-08-10

IPv6 2026—2030 实施方案提出推动 IPv6 与智能体应用融合并探索基于 IPv6 的智能体标识技术

“人工智能+信息通信”2026—2028 实施意见提出网络智能体、多智能体协同、智能体通信、自主智能体通信协议任务和智能体云化部署

这些保持为政策任务与探索方向，不提前写成协议或标识体系已经完成

## 3｜W33 优先问题 / Weekly priorities

1. **身份向网络层下沉** — GB/Z 185 身份码、ASL 可信身份与 IPv6 智能体标识之间是否形成映射
2. **通信协议层** — 自主智能体通信协议与 MCP、A2A、ITU-T F.748.93 如何分层
3. **网络 Agent** — Agent 是管理网络、运行在网络上还是成为网络原生服务主体
4. **网关与控制面** — 网关、多智能体协同与网络鉴权、路由、审计如何衔接
5. **云边端部署** — 云化、边缘和终端 Agent 是否共享身份与权限基础设施
6. **安全治理** — 高权限网络 Agent 如何实现授权、撤销、追溯与人工接管
7. **产业证据** — 政策与标准如何走向可核验部署
8. **开源与工程** — 国内开源项目是否进入身份、网关、网络与审计层

## 4｜工作假设 / Working hypotheses

### H1 — 中国智能体基础设施将出现“应用协议 + 网络底座”双层化

**证伪条件：** 后续实现长期完全停留在应用层，网络方案不产生可核验接口或部署

### H2 — 身份将成为跨层连接点

**证伪条件：** 身份码、网络标识、企业凭据和授权链长期隔离仍能形成大规模互操作

### H3 — “自主智能体通信协议”不会简单等价于 MCP 或 A2A

**证伪条件：** 后续正式文本直接采用既有协议作为统一主体而不形成独立网络通信层

## 5｜Progress Check — 2026-08-11 / 周内进展检查

### 新证据

国家标准版图显示出一条此前没有进入 W33 模型的横向轨道

`GB/T 47507-2026 人工智能 可信赖 通则` 官方页面列出发布日期 2026-04-30、实施日期 2026-08-01，但截至 8 月 11 日观察时页面状态仍显示“即将实施”

同时：

- `GB/T 47863-2026` 已发布，实施日期 2026-11-01，仍为“即将实施”
- `GB/T 47849-2026` 已发布，实施日期 2027-02-01，仍为“即将实施”
- 既有生成式 AI 标准还覆盖社会影响评估、数据安全与服务安全

### 假设状态

| 假设 | 状态 | 11 Aug 证据 |
|---|---|---|
| H1 — 应用协议 + 网络底座 | **STRENGTHENED / REFINED** | 纵向结构继续成立，但已不足以解释完整标准版图，需要增加横向保障维度 |
| H2 — 身份成为跨层连接点 | **OPEN** | 今天未发现身份码、IPv6 标识与可信赖标准之间的正式映射 |
| H3 — 独立通信协议层 | **OPEN** | 仍只有政策任务，没有新正式协议文本 |

### New H4 — 纵向互联 × 横向可信赖

中国 Agent 基础设施将更适合表示为二维结构：

```text
纵向互联：身份 → 发现 → 交互 → 工具 → 网络 → 部署
×
横向保障：可信赖 → 安全 → 社会影响 → 合规 → 评价 / 生命周期证据
```

**证伪条件：** 后续正式内容和实际实施显示横向可信赖标准与 Agent 系统没有可核验关系，或始终保持完全独立

### 状态冲突纪律

GB/T 47507 今天触发一条新的周级规则：

> **实施日期、门户状态、观察日期必须同时保存**

官方页面也可能出现状态字段与日历日期不同步，仓库不得自行抹平冲突

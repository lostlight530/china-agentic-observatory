## 2｜工作假设 / Working hypotheses

### H1 — 应用协议 + 网络底座双层化
中国智能体基础设施将同时发展应用互联语义与网络级承载能力

### H2 — 身份成为跨层连接点
身份码、网络标识、企业凭据与授权链最终需要映射

### H3 — 自主智能体通信协议形成独立层
信息通信场景更可能形成独立或补充通信要求，而不是简单等价于 MCP/A2A


### New H5 — 物理行动形成独立标准平面

中国 AI 标准体系将逐步把“能在数字系统中调用工具的 Agent”与“能在物理世界中感知、决策和行动的具身智能体”区分为相关但独立的工程平面

工作模型：

```text
PLANE 1 数字 / 网络互联
身份 → 发现 → 交互 → 工具 → 网关 → 网络

PLANE 2 横向保障
可信赖 → 安全 → 合规 → 评价 → 生命周期

PLANE 3 物理具身行动
应用框架 / 接口 → OS → 云协议 → 数据 / 仿真
→ 分级 → 评测 → 可信赖 → 伦理治理
```

**证伪条件：** 后续标准内容显示这些具身项目只是通用软件 Agent 标准的简单复用，而没有形成独立的物理系统、接口、运行、评测或治理要求

### 新问题

- 具身智能体应用框架如何映射 GB/Z 185 的身份、发现、交互和工具调用
- 具身 OS、云协议与网络 Agent 基础设施如何分层
- 机器人/具身主体的身份与权限是否需要不同于纯软件 Agent 的表达
- 可信赖通则如何落入具身可信赖要求与测评方法
- 物理安全、伦理治理和人工接管如何进入标准体系

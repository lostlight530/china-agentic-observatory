### New H6 — 具身智能数据基础设施成为独立标准化平面

具身智能将不只通过 AI 系统标准被组织，还会通过独立的数据来源、仿真合成、训练基地采集/训练和质量治理体系形成数据基础设施

**证伪条件：** TC609 数据项目与 TC28 具身系统项目长期没有技术映射、验证试点或产业联动，数据标准始终停留在通用治理层

### Weekly model refinement

```text
TC609 / DATA PLANE
source → synthetic data → training-base collection / training

                ↓

TC28 / EMBODIED SYSTEM PLANE
data generation → simulation → model → OS / cloud protocol
→ interface → evaluation → trustworthiness / ethics
```

这张 crosswalk 是本仓分析，不是官方统一架构

### 新问题

- TC609 与 TC28 是否形成正式 crosswalk
- 训练基地如何定义覆盖度、质量和可重复性
- 仿真合成数据如何做 sim-to-real 验证
- 数据 provenance 与具身评测如何绑定
- 验证试点是否产生可公开复现的实施证据

## 5｜Weekly discipline / 周级纪律

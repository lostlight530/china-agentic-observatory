## 2｜开周信号 / Week-opening signal

两个官方政策文本把这一问题变得具体

第一，《深化互联网协议第六版（IPv6）技术创新和融合应用实施方案（2026—2030年）》明确提出推动 IPv6 与智能体应用融合，并“探索基于 IPv6 的智能体标识技术”

第二，工信部《“人工智能+信息通信”创新发展实施意见（2026—2028年）》提出研发网络大模型和智能体，突破多智能体协同与智能体通信，打造自主智能体通信协议，并推动智能体云化部署

这些都仍然是政策任务与探索方向，不代表协议或标识体系已经完成

## 3｜W33 优先问题 / Weekly priorities

1. **身份向网络层下沉** — GB/Z 185 身份码、ASL 可信身份与 IPv6 智能体标识探索之间是否形成技术映射
2. **通信协议层** — “自主智能体通信协议”最终采用什么抽象，与 MCP、A2A、ITU-T F.748.93 如何分层
3. **网络 Agent** — 电信网络中的智能体是管理网络、运行在网络上，还是成为网络原生服务主体
4. **网关与控制面** — AIIA 智能体网关、多智能体协同与通信网络中的鉴权、路由、审计如何衔接
5. **云边端部署** — 智能体云化、边缘推理、终端 Agent 是否共享身份与权限基础设施
6. **安全治理** — 高权限网络 Agent 如何实现授权、撤销、追溯、人工接管和生命周期安全
7. **产业证据** — 从政策与标准走向运营商、云、工业、终端的实际部署证据
8. **开源与工程** — 国内核心开源 Agent 项目是否出现网络层、身份层或网关层架构变化

## 4｜工作假设 / Working hypotheses

### H1 — 中国智能体基础设施将出现“应用协议 + 网络底座”双层化

GB/Z 185、ASL、网关规范处理应用与互联语义，IPv6/信息通信体系逐步承载可寻址、可识别、可管理的网络级能力

**证伪条件：** 后续实现继续完全停留在应用层，网络方案不产生可核验技术接口或部署

### H2 — 身份将成为跨层连接点

身份码、Agent Card、网络标识、企业 IAM 与授权链最终必须发生映射，否则多智能体互联无法稳定跨平台运行

**证伪条件：** 各层长期维持相互隔离且仍能形成大规模互操作

### H3 — “自主智能体通信协议”不会简单等价于 MCP 或 A2A

更可能形成面向信息通信网络场景的专用要求，并与应用层开放协议互补或映射

**证伪条件：** 后续官方文本直接采用既有协议作为统一主体而不形成独立通信层

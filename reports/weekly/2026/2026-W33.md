### New H7 — 训练—验证—数据反馈闭环形成

中国具身智能标准化将逐步形成可重复的训练—验证—数据反馈闭环，使数据来源、训练场、模型训练、机器人系统、仿真/中试验证、能力评价和失败样本成为彼此可追溯的工程证据

```text
DATA
→ TRAINING GROUND
→ MODEL / ROBOT
→ SIMULATION / PILOT VALIDATION
→ EVALUATION / FAILURE EVIDENCE
→ DATA
```

**证伪条件：** 相关项目长期保持孤立，没有共享指标、正式映射、验证试点或可追溯的数据回流证据

### Cross-committee model / 跨标委会模型

```text
TC609 — DATA PRODUCTION
source → synthetic data → training-base collection

TC28 — EMBODIED AI TRAINING
embodied data training ground → models / simulation / evaluation

TC591 — HUMANOID INDUSTRIAL VALIDATION
data training ground → model training platform
→ simulation / pilot verification → capability / quality evidence
```

这张关系图是本仓分析，不是官方统一架构

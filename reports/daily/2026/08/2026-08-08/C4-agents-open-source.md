# C4｜Agents, Platforms, Open Source & Engineering / 智能体、平台、开源与工程

## Result

The domestic engineering layer should now be tracked through architecture, not product announcements alone.

AIIA’s continuing work on multi-agent collaboration and agent gateway technical requirements indicates that engineering concerns are moving toward routing, policy enforcement, interoperability, and coordination boundaries.

Open-source projects such as Nexent, DeerFlow, Astron Agent, Qwen-Agent, UI-TARS, and Trae Agent remain on the watchlist, but only official repository, release, architecture, or paper evidence should trigger durable updates.

## Judgment

The next useful comparison is not “which agent is strongest,” but which systems expose stable contracts for identity, tool access, memory, delegation, audit, and recovery.

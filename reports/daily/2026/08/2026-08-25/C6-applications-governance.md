# C6｜Applications, Security Governance, and Social Impact

Operational feedback return creates a governance question before it creates a training benefit

Returned application data can include mistakes, anomalies, privacy-sensitive content, poisoned interactions, biased samples or task-specific edge cases

Therefore:

```text
RETURN
→ provenance
→ quality evaluation
→ governance approval
→ lifecycle action
```

must remain conceptually separate from:

`RETURN → TRAIN`

**Rule:** automatic return ≠ automatic training admission

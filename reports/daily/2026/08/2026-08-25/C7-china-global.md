# C7｜China–Global Relationship

Today's China evidence is about operational dataset feedback rather than a protocol race

The useful comparison is layer-specific:

- China cases: application data return, dataset supplementation, periodic update, platform return function
- Global W35: live trust signals, relying-resource enforcement, runtime revocation propagation

Both study state change after execution, but the controlled objects differ

**Boundary:** feedback lifecycle and access-revocation lifecycle should not be forced into one national-stack comparison

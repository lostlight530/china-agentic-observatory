# C2｜Standards, Protocols, Identity, and Interconnection

Feedback return is becoming visible as an operating capability, but its semantics remain fragmented

Current public evidence does not establish one normative object that links:

- application-feedback event
- dataset / model version
- quality status
- required lifecycle action
- trusted-data-space contract / strategy
- resulting dataset state

**W35 implication:** platformization increases the need for a formal feedback-event and lifecycle crosswalk rather than reducing it

# C4｜Agents, Platforms, Open Source, and Engineering

For Agent and model systems consuming governed data, the next engineering layer is not just API access but policy-aware connectors

Important interfaces include:

- contract reference
- policy instance
- execution environment
- termination request
- behavior record
- fulfillment proof
- signature / verification

**Open question:** whether domestic Agent and data-space implementations expose these interfaces through public code or interoperable APIs

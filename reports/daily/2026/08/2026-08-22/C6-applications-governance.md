# C6｜Applications, Security Governance, and Social Impact

Today adds two governance branches after data access begins:

```text
NORMAL COMPLETION
→ fulfillment proof
→ compliance / settlement

ABNORMAL / POLICY EVENT
→ termination request
→ reason / actor / timestamp
→ downstream governance
```

A signed fulfillment proof is still not proof that the intended purpose was legitimate or that every downstream derivative use complied

**Rule:** evidence of execution ≠ evidence of semantic compliance

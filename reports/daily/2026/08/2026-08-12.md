## 0｜Executive Judgment / 核心判断

今天凌晨没有发现足以替代昨日“纵向互联 × 横向可信赖”判断的同日重大 C0/C1 发布

但国家标准信息平台当前的具身智能项目状态把中国仓的世界模型再次扩展了一层：**中国 AI 标准化已经不能只用数字 Agent、网络互联和通用可信赖描述，物理世界中的感知、决策、执行、接口、操作系统、云协议、数据、仿真、评测与伦理治理正在形成独立的具身智能标准平面**

这里最重要的不是项目数量，而是成熟度结构：应用框架及接口已进入**审查**，智能化分级进入**批准**，而云协议、操作系统、评测、可信赖和伦理治理等多个项目仍处于**起草**

所以今天的判断不是“具身智能标准已经建成”，而是：

> **数字 Agent 的互联标准、横向 AI 保障、物理具身行动开始同时进入国家标准化工作流**

### English

No same-day C0/C1 release before the 05:23 CST cut-off replaces yesterday's two-dimensional standards model. The material change is analytical: current SAMR project states reveal a third plane.

China's AI standards landscape now visibly spans digital/network agent interconnection, horizontal assurance, and physical embodied agency. Application frameworks, interfaces, operating systems, cloud protocols, simulation, data, grading, evaluation, trustworthiness, and ethics are moving through distinct standardization stages.

This is evidence of a structured standards pipeline, not evidence that a unified embodied-agent standard stack has already been published or adopted.

## 2｜The embodied stack has multiple maturity states / 具身标准栈处于不同成熟度

### 应用框架及接口

`20255554-Z-469` 当前登记状态为 **正在审查**

它直接把“具身智能体应用框架与接口”放入标准工作流，意味着物理 Agent 的系统边界和接口本身已经成为标准对象

### 智能化分级

`20252043-Z-469` 当前为 **正在批准**

分级标准意味着“智能程度”不再只作为营销标签，需要进入可描述、可比较的正式框架，但今天不能根据标题推断其具体等级定义

### 云协议、操作系统、评测和可信赖

多个项目仍处于 **正在起草**：

- 具身智能云协议要求
- 具身智能操作系统技术要求
- 具身智能评测指南
- 具身智能可信赖通用要求
- 具身智能可信赖测评指标与方法
- 具身智能伦理治理指南

**ANALYSIS** — 这说明具身路线同时在补“如何运行、如何连接、如何评价、如何信任、如何治理”几层，而不是只关注机器人硬件或模型

## 3｜From two dimensions to three planes / 从二维结构到三平面

昨日模型：

```text
纵向 Agent 互联
×
横向 AI 可信赖保障
```

今天需要升级为：

```text
PLANE 1 — DIGITAL / NETWORK AGENTS
身份 → 发现 → 交互 → 工具 → 网关 → 网络

PLANE 2 — HORIZONTAL ASSURANCE
可信赖 → 安全 → 社会影响 → 合规 → 评价 → 生命周期

PLANE 3 — EMBODIED AGENCY
应用框架 / 接口 → OS → 云协议 → 数据 / 仿真
→ 智能化分级 → 性能 / 评测 → 可信赖 → 伦理治理
```

这三平面之间存在大量潜在关系，但今天没有证据证明已经有正式 crosswalk

## 4｜Why physical agency changes the governance problem / 为什么物理行动改变治理问题

纯软件 Agent 的错误通常首先落在数字资产、账户、数据和流程上

具身智能体可以进一步影响：

- 物理空间和人员
- 机器人执行器
- 工业设备
- 移动平台
- 传感器与现实环境

因此身份、权限、人工接管、可靠性和伦理治理不再只是信息系统问题，而成为物理安全问题

这也解释了为什么“可信赖、评测、伦理治理”会和 OS、云协议、数据与仿真项目同时出现

## 5｜Workstream Findings / 分任务发现

### C1 History and policy / 历史与政策

中国 AI 路线从模型、生成式服务和网络 Agent 继续扩展到具身行动，说明“人工智能+”的现实边界正在从数字流程深入物理生产与生活系统

### C2 Standards and protocols / 标准与协议

今天最重要的是状态纪律：审查、批准和起草是三个完全不同的成熟度，不能统称“即将发布”

### C3 Research and models / 科研与模型

具身智能标准版图同时包含大模型系统、智能化分级、性能和评测，说明研究对象必须把模型能力与物理系统行为分开

### C4 Agents and open source / 智能体与开源

国内 Agent 架构观察需要新增 OS、simulation、robot interface、cloud protocol 和 physical safety 层，不再只看 memory、tool、workflow、gateway

### C5 Infrastructure and industry / 基础设施与产业

云协议、操作系统、数据生成平台、仿真平台等项目意味着具身基础设施正在被作为完整工程链观察

### C6 Applications and governance / 应用与治理

具身可信赖与伦理治理项目强化昨天 H4：横向保障不是只服务语言模型，它可能贯穿到物理 Agent

### C7 China–Global / 中外路线

今天不强行寻找国外一一对应标准。具身智能国际比较必须按接口、OS、云协议、性能、评测、安全和伦理分别找同层来源

## 6｜Changed Judgments / 判断修正

### H4 strengthened

“纵向互联 × 横向可信赖”不仅适用于数字 Agent，具身智能项目也出现可信赖与测评分支

### New H5

中国 AI 标准体系需要一个独立的**物理具身行动平面**，不能把机器人/具身系统简单塞进通用软件 Agent 分类

## 7｜Stable Judgments / 稳定判断

- 标准计划不等于发布标准
- “正在批准”不等于已批准发布
- “正在审查”不等于即将生效
- 相近标准列表不证明正式技术映射
- 具身智能体与软件 Agent 相关，但不能假设协议、身份和治理完全相同
- 物理行动扩大风险后，能力验证与治理证据的重要性只会增加

## 8｜Uncertainties / 不确定项

1. 具身智能体应用框架如何与 GB/Z 185 互联标准映射
2. 具身 OS 与云协议分别负责哪些边界
3. 软件 Agent 身份码能否直接表示机器人/物理智能体
4. 可信赖通则与具身可信赖要求之间的正式关系
5. 分级标准最终如何定义智能化层级
6. 评测如何覆盖现实环境、仿真与安全接管
7. 伦理治理如何转化为可执行工程约束

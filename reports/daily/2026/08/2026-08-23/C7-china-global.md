# C7｜China–Global Relationship

W34 reveals an interesting parallel without collapsing the two systems

Global Agent governance this week moved from workspace controls toward provenance, admission and evidence lifecycle

China's data-governance research moved from feedback and quality evaluation toward circulation, digital contracts, usage control and fulfillment evidence

Both trajectories make machine-readable evidence more operational

But the comparison unit must remain exact:

- software artifact provenance is not dataset quality evidence
- Kubernetes admission is not data-space usage control
- Agent authority is not dataset credentialing
- attestation revocation is not contract termination

The useful common abstraction is narrower: **evidence increasingly participates in real policy decisions**

# Circulation Gets a Contract / 流通获得合约约束
## China AI Daily Research Report / 中国人工智能每日研究报告
### 2026-08-21

**Observation cut-off / 观察截止：2026-08-21 06:43 CST**

## 0｜Executive Judgment / 核心判断

W34 前四天已经把反馈链从模型应用反馈推进到质量评测、结果互认、标识凭证与数据集流通

今天最重要的新层不是“数据还能不能交易”，而是：**数据进入真实流通后，如何持续限制使用方式，并留下履约证据**

全国数标委在国家数据局指导下已正式发布《可信数据空间 数字合约技术要求》《可信数据空间 使用控制技术要求》《可信数据空间 技术能力评价规范》等技术文件

《可信数据空间 技术架构》与使用控制技术文件进一步给出一条明确的工程链：

```text
DATA PRODUCT / DATASET
→ USAGE APPLICATION
→ DIGITAL CONTRACT
→ USAGE-CONTROL POLICY
→ POLICY DELIVERY
→ BEHAVIOR VALIDATION
→ OPERATION EXECUTION
→ RECORD / EVIDENCE RETURN
→ COMPLIANCE / SETTLEMENT
```

因此昨天的：

```text
quality evidence
→ credential
→ compliance
→ publish / list / exchange
```

今天必须继续延伸为：

```text
circulation
→ contract
→ usage policy
→ execution control
→ performance evidence
```

核心判断是：

> **Data circulation is incomplete if governance stops at transaction approval**
>
> **数据完成交易，不等于治理已经结束**

但状态边界必须保留：这些是已经发布的可信数据空间**技术文件 / 技术架构**与验证试点成果，不应被误写成“所有全国数据交易已经统一采用同一数字合约系统”，也不等于所有数据集平台流通流程已经和可信数据空间技术栈完成正式系统级打通

## 1｜Digital contract becomes an executable policy carrier / 数字合约成为可执行策略载体

可信数据空间技术架构明确设置数字合约接口，包括策略模板、合约签订和备案，并把数据使用控制策略纳入合约信息

这与普通“交易合同”不是同一观察对象

本仓关注的是：合约是否能够把**可执行的使用约束**传递给数据使用环境

**ANALYSIS** — quality / identity evidence determines whether data may enter circulation, while digital contract begins to determine what may happen after access is granted

## 2｜Usage control moves beyond access control / 使用控制超越一次性访问控制

使用控制技术文件把控制目标进一步拆成：

- 策略解析
- 行为校验
- 环境构建
- 操作执行
- 行为记录与存证回传
- 异常情况下终止执行

并明确数据访问、分析、计算、处理和销毁等行为都可能属于约束对象

因此：

> **access granted ≠ unrestricted use**

## 3｜Evidence now appears on both sides of circulation / 证据开始出现在流通前后两侧

W34 到今天已经形成双向证据结构：

```text
PRE-CIRCULATION EVIDENCE
quality result
+ dataset identity / credential
+ compliance / rights material

POST-CIRCULATION EVIDENCE
digital contract
+ usage-control decision
+ behavior record
+ performance / compliance proof
```

**ANALYSIS** — 质量证据解决“是否值得被使用”，使用控制证据开始解决“是否按约定被使用”

## 4｜Trusted data space is not the same as national dataset platform / 可信数据空间 ≠ 国家数据集平台

国家数据集管理服务平台承担数据集目录、发布、凭证、质量测评、检索与供需服务

可信数据空间则是一条数据流通利用基础设施技术路线，强调连接器、数字合约、使用控制、互操作和安全保障

今天没有证据允许写成二者已经形成一个统一后台系统

更准确的判断是：

> **它们开始构成相邻的治理层，但正式 crosswalk 仍需寻找**

## 5｜Workstream Findings / 分任务发现

### C1 History and policy / 历史与政策

中国数据治理路线正在从“促进供给与流通”继续进入“流通后的可控使用”，这使数据市场与技术治理不再是两个独立议题

### C2 Standards and protocols / 标准与协议

数字合约和使用控制技术文件已经正式发布，证据强度高于普通研究报告或征求意见稿，但仍属于技术文件体系，不应自动等同于 GB/T 国家标准

### C3 Research and models / 科研与模型

AI 训练场景的数据使用可能涉及处理、派生、再训练和输出，因此模型上下文本身可能成为 usage-control policy 的适用条件

### C4 Agents and open source / 智能体与开源

Agent 自动发现、采购、调用数据后，未来更重要的问题是：Agent 是否能继承并持续遵守数据使用策略，而不是只有人类用户在交易前确认一次

### C5 Infrastructure and industry / 基础设施与产业

连接器开始成为 policy enforcement point：执行数字合约约束、记录行为，并在异常条件下阻断操作

### C6 Applications and governance / 应用与治理

今天治理重心从“准入”继续进入“履约”：谁使用、在什么环境、进行什么处理、是否允许下载 / 计算 / 销毁，都需要可执行和可追溯

### C7 China–Global / 中外路线

中国可信数据空间中的 digital contract / usage control 与全球 data-space / policy-enforcement 思路可以按“usage policy / connector / evidence”层比较，但不能把名称相似直接当作协议互操作

## 6｜W34 Hypothesis Movement / W34 假设变化

- **H1 — STRENGTHENED AGAIN:** feedback / data infrastructure now extends through post-circulation use governance
- **H2 — SUPPORTED / unchanged**
- **H3 — STRENGTHENED AGAIN:** provenance matters not only for evaluation but for enforcing contract scope
- **H4 — STRENGTHENED AGAIN:** formal crosswalk must now include national platform, trusted data space, connector and usage-control semantics
- **H5 — OPEN:** physical-validation failure still lacks a direct standard mechanism for generating new data tasks
- **H6 — STRENGTHENED AGAIN:** governance extends from quality / rights / compliance into post-access behavior
- **H7 — SUPPORTED / unchanged**
- **H8 — STRENGTHENED:** portable evidence becomes more useful when contract and usage-control layers can consume it
- **H9 — STRENGTHENED / REFINED:** circulation input is only the beginning of a longer usage-governance lifecycle
- **H10 — NEW:** digital contract and usage control become a post-circulation governance layer

## 7｜New Durable Candidates / 新耐久候选

> **circulation approval ≠ unrestricted usage**

> **dataset credential ≠ usage authorization**

> **digital contract ≠ automatic compliance**

> **policy delivery ≠ policy execution**

> **behavior log ≠ proof of correct use**

> **technical file ≠ universal nationwide implementation**

## 8｜Watch / 下一步

1. 国家数据集平台与可信数据空间是否出现正式 metadata / credential / contract crosswalk
2. 质量评测报告能否被 digital contract 直接引用
3. 标识凭证是否能绑定 usage-policy scope
4. 连接器的履约证明格式是否可跨平台互认
5. usage-control violation 是否触发 credential / quality-result / access revocation
6. AI / Agent 训练任务是否出现专门的 usage-control policy profile
7. 数据衍生物和模型输出是否继承原始数据使用限制

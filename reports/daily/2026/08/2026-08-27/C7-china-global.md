# C7 — China & Global

The China line and global line converge on a common systems principle: **state change needs memory**

Global W35 asks how an incident records what survived stop and what remediation changed next

China W35 asks how evaluation-driven optimization records the prior dataset state, resulting version and later model/evaluation state

The objects differ, but the architecture rhyme is strong:

```text
event → governed action → versioned state transition → later evidence
```

**Boundary:** architectural similarity ≠ formal crosswalk or shared standard

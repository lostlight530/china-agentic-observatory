# C4 — Agents & Open Source

The version-management question extends directly to Agent systems

If an Agent evaluation diagnoses a capability gap, later evidence needs to identify:

- Agent/model version
- dataset version used for the diagnostic baseline
- data optimization task
- resulting dataset version
- resulting Agent/model version

Today's evidence strengthens the data side of that chain but does not establish a common Agent lifecycle schema

**Boundary:** dataset provenance ≠ Agent authority provenance

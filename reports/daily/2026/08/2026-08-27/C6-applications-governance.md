# C6 — Applications & Governance

Version identity is necessary but not sufficient for lifecycle governance

A new dataset version still needs independent answers for:

- quality evaluation
- compliance / rights status
- provenance completeness
- approval for training or application
- supersession / withdrawal conditions

Therefore:

```text
new version ≠ approved version ≠ training-admitted version
```

The governance gap remains the linkage between diagnosis, work item, version transition and later approval

# C6｜Applications, Security Governance, and Social Impact

Feedback loops create a governance problem as well as a learning opportunity

Not every application trace should become training data

A governed feedback path must distinguish:

- normal success
- recoverable failure
- unsafe behavior
- user correction
- adversarial or poisoned input
- privacy-sensitive interaction
- out-of-distribution event

**W34 doctrine candidate:** feedback value, safety, consent, provenance, and retraining eligibility must be evaluated separately

# C4｜Agents, Platforms, Open Source, and Engineering

W34 raises the engineering bar for domestic Agent and embodied-AI projects

The observatory should now look for artifacts that make feedback traceable:

- trajectory / episode IDs
- task outcome labels
- failure and recovery records
- dataset provenance
- simulation versus real-world source labels
- model / policy version
- evaluation linkage
- retraining or dataset-revision records

**Working rule:** an application claiming a data flywheel should expose evidence that outcomes actually affect future data or model state

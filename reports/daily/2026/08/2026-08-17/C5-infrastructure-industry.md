# C5｜Chips, Compute, Data, Terminals, and Industrial Infrastructure

The data flywheel implies infrastructure beyond dataset storage

A deployable loop needs:

```text
data collection
→ secure storage / provenance
→ training infrastructure
→ application telemetry
→ evaluation
→ feedback processing
→ dataset revision
→ retraining
```

The high-quality dataset implementation plan also links datasets to national data infrastructure, trusted data spaces, storage capacity, quality evaluation, and application validation

**W34 question:** which of these components become shared industrial infrastructure rather than project-local pipelines

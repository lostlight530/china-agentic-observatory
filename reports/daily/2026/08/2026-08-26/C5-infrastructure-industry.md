# C5｜Chips, Compute, Data, Terminals, and Industrial Infrastructure

W35 now has three increasingly concrete data-lifecycle layers:

```text
application feedback / operating data
→ return function
→ evaluation / diagnosis
→ targeted dataset optimization
```

The infrastructure implication is that dataset systems need more than storage and annotation pipelines

They increasingly need versioned evaluation evidence, diagnosis, task creation, data-production tooling, approval and later comparison

**Open edge:** public national evidence still does not expose one interoperable lifecycle state machine connecting these layers

# C6｜Applications, Security Governance, and Social Impact

Evaluation-guided data optimization creates a governance problem as well as an engineering loop

Returned or newly collected data may carry privacy, safety, poisoning, bias, representativeness and rights constraints

Evaluation diagnosis therefore should not imply automatic training admission

**Durable rule:** capability gap → data need is a valid planning transition; data need → approved reusable training data still requires quality and governance gates

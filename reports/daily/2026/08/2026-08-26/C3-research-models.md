# C3｜Research, Models, Algorithms, and Evaluation

The `模数共振` action explicitly creates evaluation datasets for industry models and specialized Agents and uses evaluation results to guide targeted dataset optimization

This strengthens the need to separate diagnostic evidence from reusable training data

```text
evaluation evidence
→ diagnosed capability gap
→ data requirement
→ new / relabeled / recollected / synthetic training data
```

**Boundary:** evaluation dataset ≠ training dataset, and model improvement does not by itself prove which data change caused the improvement

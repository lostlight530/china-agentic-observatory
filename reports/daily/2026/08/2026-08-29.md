## 4｜Research, Models, and Infrastructure / 科研、模型与基础设施

Friday 已经把核心问题推进到 version-scoped quality

Saturday 进一步把问题收窄为 applicability：

```text
quality_result(dataset_v1)
?
valid for dataset_v2
```

如果 `v2` 发生了实质变化，例如：

- 重采集
- 重标注
- 去重 / 清洗
- 样本重加权
- 合成数据加入
- 数据过滤或删除

那么旧质量结果是否仍有效，不能仅凭 dataset name 推断

但今天仍没有发现全国统一公开规则明确规定：

- 哪类变化必须完整重评
- 哪类变化只需局部重评
- 哪类变化允许沿用既有结果
- 旧质量结果何时自动失效或被 supersede

所以：

> **version-scoped quality ≠ mandatory automatic re-evaluation**

## 5｜Agents, Open Source, and Industry / 智能体、开源与产业

对于消费高质量数据集的模型 / Agent 平台，真正可审计的输入不应只是：

```text
dataset_name + generic_quality_label
```

更合理的分析对象是：

```text
dataset_version_id
+ provenance
+ quality_result_id
+ applicability scope
+ governance / rights state
```

这是观察站的结构分析，不代表全国统一接口已经存在

## 6｜Applications, Security, and Society / 应用、安全与社会

质量结果仍不能替代：

- 权利状态
- 合规状态
- 使用控制
- 数字合约
- 访问 / 凭证状态

因此版本作用域的质量证据即使成熟，也只是更大治理链中的一个对象

```text
quality pass
≠
rights approval
≠
usage authorization
```

## 7｜China–Global Relationship / 国内外路线关系

中国当前可以观察到质量测评、评测系统、版本 / 溯源等对象分别推进

但本轮没有发现一个正式公开证据证明它们已经形成：

- 全国统一 version → quality-result crosswalk
- 与全球 Agent / 数据治理协议的正式互操作映射
- 自动化再评测与训练准入闭环

因此跨体系关系继续保持为：

> **结构可比较，正式 crosswalk 未证实**

# C4｜Agents, Platforms, Open Source, and Engineering

国内 Agent 工程观察需要正式增加物理系统层：

- embodied interface
- robot / embodied OS
- cloud protocol
- simulation
- data generation / training environment
- physical action and dexterous manipulation
- safety takeover
- hardware-software co-design

这意味着只看 skill、memory、tool、workflow、gateway 已经不足以描述中国 Agent 工程前沿

后续开源项目只有出现这些架构级变化时才进入长期对象卡

# C2｜Standards & Protocols / 标准与协议

## Layer map

| Layer | Current evidence | Status |
|---|---|---|
| National interconnection | GB/Z 185.1—185.7 | Current national guiding technical documents |
| Trust and authorization | ASL | Released industry protocol framework |
| Multi-agent collaboration / gateway | AIIA workshops | Technical specification discussion, not final standard |
| International interoperability | ITU-T F.748.93 | Consented under AAP, not yet recorded as final Recommendation |
| Agent benchmark | ITU-T F.ACAIA-B | Under study |

## Judgment

China’s agent standards landscape is becoming layered rather than monolithic

The most important methodological rule is state precision: **current standard ≠ released protocol framework ≠ workshop draft ≠ consented international work item ≠ under-study item**

# Evidence Enters Circulation / 证据进入流通层
## China AI Daily Research Report / 中国人工智能每日研究报告
### 2026-08-20

**Observation cut-off / 观察截止：2026-08-20 08:02 CST**

## 0｜Executive Judgment / 核心判断

W34 前三天已经把中国仓的 feedback 路线推进到：

```text
反馈回流
→ 质量评测
→ 结果包
→ 互认
```

今天真正值得补上的下一层，是这些证据如何进入**发布、凭证、供需匹配和流通基础设施**

国家数据集管理服务平台已于 2026 年 4 月 29 日正式发布并启动试运行，面向数据集供给方提供数据集发布、凭证申领、质量测评等服务；官方材料同时明确平台当前已开放供需发布、全域检索、凭证申领等基本功能

国家数据局官方专家解读进一步说明：平台一期已经上线，并提出依托供需对接与质量评测功能打造标准化、可验证的数据集产品；平台还将支持**已发布、已评测并获得标识凭证**的数据集，在合规前提下与数据交易机构对接，进行挂牌、上架和交易

因此今天的核心判断是：

> **高质量数据集的评测证据正在从“评价结果”进入“流通输入”问题**

但这里有一个必须写死的状态边界：

> **标识凭证 ≠ 质量证书**

平台把凭证申领和质量测评列为不同服务，这意味着 dataset identity、quality evidence、compliance review 和 circulation decision 不能被压缩成同一个“认证”字段

## 1｜From portable evidence to circulation / 从可携带证据到流通

昨天 W34 的模型是：

```text
FEEDBACK DATA
→ PROVENANCE
→ QUALITY EVALUATION
→ EVALUATION RESULT / PACKAGE
→ MUTUAL-RECOGNITION DECISION
```

今天继续向后扩展：

```text
DATASET IDENTITY / CREDENTIAL
        +
QUALITY EVIDENCE
        +
COMPLIANCE / RIGHTS MATERIAL
        ↓
PUBLISH / DISCOVER
        ↓
PROCUREMENT / LISTING / EXCHANGE
        ↓
APPLICATION / FEEDBACK
```

这是本仓综合模型，不是国家数据局公布的统一技术架构

## 2｜National platform provides an operational service layer / 国家平台补出运行服务层

**OFFICIAL FACT** — 国家数据集管理服务平台由国家数据局指导、国家数据发展研究院建设运营，2026 年 4 月 29 日正式发布并启动试运行

**OFFICIAL FACT** — 平台面向供给方提供数据集发布、凭证申领、质量测评等服务，面向需求方提供查询检索、需求发布和供需对接

**OFFICIAL FACT** — 官方地方治理解读明确提到，平台支持上传数据来源和合法合规声明材料，并通过准入检测、多级审核等措施前移合规关口，同时可申请符合国家标准的评测报告

**ANALYSIS** — W34 的“质量证据可携带性”开始获得一个现实承载面：结果不再只存在于标准文本，而可能进入一个跨地区、跨主体的数据集管理与供需系统

## 3｜Credential, evaluation and circulation are separate / 凭证、评测与流通必须分开

当前官方材料至少表现出三个不同对象：

```text
IDENTIFIER CREDENTIAL
回答：这是哪一个数据集 / 哪个登记对象

QUALITY EVALUATION
回答：在什么方法和范围下，这个数据集表现如何

CIRCULATION / LISTING DECISION
回答：这个数据集能否在特定合规与交易环境中发布、采购、挂牌或上架
```

因此今天新增三条边界：

> **dataset credential ≠ quality certificate**

> **quality report ≠ listing approval**

> **listing / trading ≠ universal model fitness**

## 4｜The platform connects evidence to a market boundary / 平台把证据连接到市场边界

国家数据局官方解读提出，系统将推动已发布、评测和获得标识凭证的数据集在合规前提下进入挂牌、上架和交易

这说明“互认”的最终价值不只是减少重复测试，还可能降低跨组织数据流通的信任与解释成本

但这里仍不能抢跑：

- 国家平台当前仍是试运行阶段
- “一次测评、全国互认”仍是政策实施方向
- `20256913-T-907` 当前仍处于征求意见
- `20262581-Z-907` 质量评测系统技术要求仍处于起草
- 平台存在质量测评服务，不等于全国所有行业已经采用统一评测结果

## 5｜W34 Progress Check / W34 第三次进展检查

### H1 — Feedback-to-data becomes an explicit infrastructure problem

**STRENGTHENED AGAIN**

反馈和质量问题现在不仅连接标准化，也连接国家级数据集管理与流通服务平台

### H2 — Model-application feedback becomes a dataset quality gate

**SUPPORTED / unchanged**

政策仍明确“数据质量验证 + 模型应用反馈”，今天没有证据改变这一方向

### H3 — Embodied feedback requires source-aware provenance

**STRENGTHENED**

平台公开材料把数据来源、合法合规声明和准入审核放到发布 / 服务过程里，说明来源语义在流通前仍不能丢失

### H4 — Cross-committee lifecycle mappings will become necessary

**STRENGTHENED / REFINED**

随着国家平台与地方、行业系统对接，标准 crosswalk 的问题进一步变成系统间 metadata / credential / evaluation-result mapping 问题

### H5 — Application validation becomes backpressure on data construction

**OPEN**

今天仍没有正式机制把具体物理验证失败自动生成新数据任务

### H6 — Feedback governance becomes as important as feedback volume

**STRENGTHENED AGAIN**

数据来源声明、合规审核、敏感信息检测、质量评测与流通决策说明“能流通”需要治理条件，而不仅是数据量与质量分数

### H7 — Quality evaluation becomes an explicit feedback gate

**STRENGTHENED / OPERATIONAL SERVICE EVIDENCE**

除了标准项目外，国家平台已经把质量测评作为供给方服务能力

这仍不等于统一国家标准已经发布

### H8 — Quality evidence becomes a portability object

**STRENGTHENED / REFINED**

可携带质量证据现在开始有明确的流通使用场景：供需匹配、采购、挂牌、上架和交易

### New H9 — Quality evidence becomes a circulation input

标准化质量结果、数据集身份凭证与合规材料将越来越作为数据集跨组织流通、采购和交易的组合输入，而不是只作为内部质量报告

**证伪条件：** 全国和行业数据流通长期仍主要依赖重新人工解释与重复测评，质量结果、数据集身份和合规材料不能形成可复用的流通证据包

## 6｜Workstream Findings / 分任务发现

### C1 History and policy / 历史与政策

政策路线正在从“建设高质量数据集”推进到“管理、评测、供需对接和价值释放”的全生命周期组织

### C2 Standards and protocols / 标准与协议

`20256913-T-907` 的征求意见状态与国家平台的质量测评服务属于不同证据层

标准内容规定评测语义，平台服务承载评测 / 流通流程；二者不能混写

### C3 Research and models / 科研与模型

数据集的模型适配性和应用反馈仍然是质量判断的一部分，但不能因为某个模型表现良好就推导所有模型 / 行业场景都适用

### C4 Agents and open source / 智能体与开源

对 Agent 和具身项目而言，未来数据包如果进入跨组织采购与复用，将需要同时保存 dataset identity、source provenance、quality evidence 和 usage boundary

### C5 Infrastructure and industry / 基础设施与产业

国家数据集管理服务平台提供了连接目录、凭证、质量测评、供需对接和地方 / 行业系统的基础设施层

这使“互认”开始具有系统承载面，而不只是一条政策口号

### C6 Applications and governance / 应用与治理

流通扩大了错误评测或错误适用的影响范围

因此数据来源、合规声明、质量评测、适用范围、有效期、撤销 / 重测条件应该被分开治理

### C7 China–Global / 中外路线

全球软件供应链正在使用 cryptographic attestation 让 provenance 随 artifact 流动；中国高质量数据集路线则正在把质量评测、身份凭证和流通服务组织到国家数据集平台

两者都体现“evidence portability”，但对象、治理语义和制度结构不同，不能直接等同

### C8 Synthesis / 综合

W34 当前链条已经从：

```text
反馈
→ 评测
→ 结果互认
```

推进到：

```text
反馈 / 数据来源
→ 质量评测
→ 结果包
→ 数据集身份 / 凭证
→ 合规审核
→ 发布 / 检索
→ 采购 / 挂牌 / 交易
→ 应用反馈
```

下一步真正需要的是：这些不同证据对象是否会形成正式 schema、接口、有效期、撤销与跨平台映射规则

## 7｜New Durable Candidates / 新耐久候选规则

> **dataset credential ≠ quality certificate**

> **quality report ≠ circulation approval**

> **mutual recognition ≠ mandatory acceptance**

> **listing / trading ≠ government endorsement**

> **circulation ≠ universal model fitness**

> **platform trial ≠ mature nationwide market mechanism**

## 8｜Watchlist / 下一轮观察点

1. 国家平台的标识凭证具体承载哪些 metadata，是否与质量评测报告关联
2. 质量评测报告是否拥有标准化机器可读格式
3. “一次测评、全国互认”是否进入平台具体流程或试点名单
4. 数据集凭证、评测结果、合规状态是否存在有效期 / 撤销 / 重测机制
5. 数据交易所与国家平台对接时如何传递质量与合规证据
6. 具身智能数据集是否进入可公开检查的评测、凭证和流通案例
7. 模型应用反馈能否在流通后继续回到数据集版本迭代

# C4｜Agents, Platforms, Open Source, and Engineering

Agent-mediated data use raises a new engineering requirement

If an Agent discovers, purchases, accesses or transforms a dataset, usage constraints must survive the automation boundary

The system therefore needs more than human-facing terms:

- machine-readable scope
- policy propagation
- action enforcement
- evidence return
- revocation / termination behavior

**Open question:** whether domestic Agent platforms expose these constraints as first-class runtime policy rather than external compliance documentation

# C5｜Chips, Compute, Data, Terminals, and Industrial Infrastructure

Today’s infrastructure object is the trusted-data-space connector

The connector is not only a transport endpoint. In the published technical architecture it can act as a policy-execution point that receives control instructions, executes constrained operations, records behavior and returns evidence

```text
service platform
→ policy / contract
→ connector
→ controlled environment
→ operation
→ evidence return
```

**Durable candidate:** connector infrastructure is becoming part of the governance plane, not just the data plane

# C7 — China ↔ Global

## 2026-08-31 finding

China and global Agent/AI systems increasingly expose comparable lifecycle questions through different institutional mechanisms.

```text
China:  policy / standards / technical files / national platforms / sector cases
Global: protocols / cloud IAM / runtime controls / provenance / product implementations
```

Comparisons must match the layer and maturity state.

`structural comparability ≠ formal interoperability`

ITU-T F.748.93 remains a useful bridge signal, but consent under AAP is not final Recommendation publication.

# C6｜Applications, Security Governance, and Social Impact

Evidence reuse increases governance blast radius

If one evaluation result is reused across procurement, listing, exchange or downstream model development, poor scoping or stale evidence can propagate widely

Circulation therefore needs at least:

```text
identity / version
→ provenance
→ compliance / rights
→ quality evidence
→ applicability scope
→ validity / re-evaluation
→ circulation decision
```

**Rule:** quality approval and circulation approval should remain separate but composable

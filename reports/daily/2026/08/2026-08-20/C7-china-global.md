# C7｜China–Global Relationship

Today both observatories touch evidence portability, but at different layers

Global software provenance uses cryptographic build attestations so consumers can verify where and how an artifact was built

China's high-quality-dataset route is organizing identity, quality evaluation, compliance material, publishing and circulation through a national data-service layer

The common abstraction is portable evidence

The governance objects are different and should not be collapsed into one model

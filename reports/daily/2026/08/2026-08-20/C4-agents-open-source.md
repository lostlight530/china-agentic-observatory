# C4｜Agents, Platforms, Open Source, and Engineering

For Agent and embodied-AI projects, reusable datasets increasingly need more than a download URL

A cross-organization data package may need to preserve:

- dataset identity / version
- source provenance
- rights / compliance material
- evaluation method and result
- model / task applicability
- usage boundary

The national platform provides evidence that dataset identity, publishing and evaluation are becoming service-layer objects

**Open question:** whether open-source Agent projects will consume these metadata fields in machine-readable form

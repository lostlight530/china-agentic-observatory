# C6 — Applications, Security Governance, Social Impact

## Governance finding

Quality and governance must remain separate but composable

A new dataset version may require renewed evidence across several independent dimensions:

```text
quality
provenance
rights / compliance
usage-control scope
privacy / security
application fitness
```

A quality pass must not silently renew rights or usage authorization

Likewise, valid provenance does not prove model fitness

## Friday rule

```text
new version ≠ inherited quality status
quality pass ≠ governance approval
```

## Open question

Which changes require full re-evaluation, partial re-evaluation, or no re-evaluation remains unstandardized in the evidence reviewed today

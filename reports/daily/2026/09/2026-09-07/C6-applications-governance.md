# C6 — Applications, Security Governance and Social Impact

The SG17 Q16/17 meeting surface separates multiple agent-security concerns: invocation, data, autonomous-agent security, orchestration and PII interactions.

This supports a bounded architecture observation: agent governance is being decomposed into distinct control objects.

It does not establish a unified security architecture, operational deployment or conformance result.

Boundary: `security work item != deployed control`.

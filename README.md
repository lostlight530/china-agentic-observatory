## Research Discipline / 研究纪律

- **C0–C4 权威来源优先**
- **征求意见 ≠ 已发布标准**
- **质量评测 ≠ 结果互认**
- **标识凭证 ≠ 质量证书**
- **质量报告 ≠ 流通批准**
- **结果互认 ≠ 强制接受**
- **挂牌 / 上架 / 交易 ≠ 政府背书或全场景适用**
- **平台试运行 ≠ 成熟全国市场机制**
- **数据飞轮 ≠ 已闭环系统**
- **不为了日报制造趋势**
- **不运行、部署或验证外部项目能力**

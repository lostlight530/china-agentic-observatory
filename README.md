## Research Discipline / 研究纪律

- **C0–C4 权威来源优先 / Authoritative sources first**
- **事件日期、发布日期、生效日期、观察日期严格区分**
- **政策目标 ≠ 已完成能力**
- **国家标准 ≠ 产业研讨 ≠ 国际 consent 状态**
- **企业路线 ≠ 国家路线 · 单个项目 ≠ 全国性事实**
- **事实、外部声明、本仓分析与不确定项严格区分**
- **不为了日报制造趋势**
- **新证据要求时必须修正旧判断**
- **不运行、部署或验证外部项目能力**

## Boundary / 边界

This repository is a research observatory, not a policy endorsement platform, product ranking site, code-validation laboratory, general news archive, certification service, or investment/geopolitical forecasting service

本仓库研究中国人工智能现实，但不把政策目标等同于现实能力，不把企业宣传等同于产业事实，也不以任何单一国际框架替代中国自身的历史与制度语境

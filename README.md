## Research Discipline / 研究纪律

- **C0–C4 权威来源优先**
- **事件日期、发布日期、实施日期、门户状态、观察日期严格区分**
- **状态冲突必须显式保存，不自行抹平**
- **政策目标 ≠ 已完成能力**
- **发布 ≠ 生效 ≠ 采用**
- **企业路线 ≠ 国家路线**
- **不为了日报制造趋势**
- **不运行、部署或验证外部项目能力**

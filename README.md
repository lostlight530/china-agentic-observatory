## Research Discipline / 研究纪律

- **C0–C4 权威来源优先**
- **起草 ≠ 审查 ≠ 批准 ≠ 发布**
- **标准计划 ≠ 已生效标准**
- **事件日期、发布日期、实施日期、门户状态、观察日期严格区分**
- **政策目标 ≠ 已完成能力**
- **标准矩阵关系 ≠ 已存在正式 crosswalk**
- **企业路线 ≠ 国家路线**
- **不为了日报制造趋势**
- **不运行、部署或验证外部项目能力**

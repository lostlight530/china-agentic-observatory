## Research Discipline / 研究纪律

- **C0–C4 权威来源优先 / Authoritative sources first**
- **事件日期、发布日期、生效日期、观察日期严格区分**
- **政策目标 ≠ 已完成能力**
- **探索方向 ≠ 标准发布 · 协议任务 ≠ 已发布协议**
- **国家标准 ≠ 产业研讨 ≠ 国际 consent 状态**
- **企业路线 ≠ 国家路线 · 单个项目 ≠ 全国性事实**
- **事实、外部声明、本仓分析与不确定项严格区分**
- **不为了日报制造趋势**
- **新证据要求时必须修正旧判断**
- **不运行、部署或验证外部项目能力**
